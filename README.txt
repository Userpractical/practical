PRACTICAL CODE LIBRARY

Run locally:
1. Extract this ZIP file.
2. Open the practical-code-library folder in VS Code.
3. Open index.html in a browser, or use the VS Code Live Server extension.
4. Click a practical and press Copy Code.

Deploy free with GitHub Pages:
1. Create a GitHub repository, for example practical-code-library.
2. Upload index.html, style.css, script.js, and practicals.js to the repository root.
3. Open repository Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select branch main and folder /(root), then Save.
6. Wait for the Pages URL to appear in Settings > Pages.

Alternative: Netlify
1. Open https://app.netlify.com/drop
2. Drag and drop the extracted practical-code-library folder.
3. Netlify will publish the static website and provide a public URL.

No Python, Conda, pip packages, or backend server are required.
Note: The practical source files are included as uploaded. Review and test code before running/submitting it.
